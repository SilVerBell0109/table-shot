# DeskShot

맥의 **데스크 뷰(Desk View)** 카메라로 책상 위 종이나 아이패드를 즉시 캡처하는 메뉴바 앱입니다.
캡처하면 이미지가 **클립보드에 복사**되고 동시에 **PNG 파일로 저장**됩니다. 챗봇에 붙여넣거나 카톡으로 보내는 등 활용은 직접 하면 됩니다. (자동 연동 없음 — 캡처까지만)

## 지원 기종

데스크 뷰 카메라(12MP 센터 스테이지 내장 카메라)가 있는 맥에서만 동작합니다.

- MacBook Air M4 이상 (2025년~)
- MacBook Pro M4 / M4 Pro / M4 Max 이상 (2024년 말~)
- iMac (M4, 2024년)

지원하지 않는 맥에서 실행하면 안내 화면이 뜨고 캡처는 비활성화됩니다.

## 빌드

```bash
./packaging/make-app.sh
```

`DeskShot.app`이 프로젝트 루트에 생성됩니다.

## 설치 & 첫 실행

이 앱은 코드 서명이 되어 있지 않습니다. 첫 실행만 아래 절차를 따르세요.

1. `DeskShot.app`을 `/Applications` 등 원하는 곳으로 옮깁니다.
2. Finder에서 `DeskShot.app`을 **우클릭 → 열기**.
3. 경고 대화상자에서 **열기**를 누릅니다. (이후부터는 더블클릭으로 바로 실행됩니다)
4. 처음 캡처하거나 미리보기를 열 때 **카메라 권한**을 허용합니다.
   - 거부했다면 메뉴바 메뉴의 "시스템 설정 열기"로 다시 허용할 수 있습니다.

## 사용법

메뉴바의 카메라 아이콘을 누르면 메뉴가 열립니다.

- **찍기** — 현재 데스크 뷰 프레임을 캡처
- **미리보기 열기** — 라이브 영상 + 큰 "찍기" 버튼
- **저장 폴더 열기** — 저장 위치를 Finder로 열기
- **설정…** — 저장 폴더 변경, 단축키 확인

캡처 방법 3가지 (모두 동일하게 동작):

1. **전역 단축키** `⌘⇧2` — 다른 앱을 쓰는 중에도 캡처
2. **메뉴바 "찍기"**
3. **미리보기 창의 "찍기" 버튼**

캡처하면 셔터음과 화면 가장자리 플래시로 알려 주고,
이미지는 클립보드에 복사 + `~/Pictures/DeskShots/desk-YYYYMMDD-HHmmss.png`로 저장됩니다.
붙여넣기는 `⌘V`.

## 저장 위치

기본값은 `~/Pictures/DeskShots`. 설정에서 변경할 수 있습니다.
